# Frontend

Frontend отсутствует: в репозитории не найдены `package.json`, исходники web/mobile-клиента, frontend build-конфигурация или статические UI-артефакты.

Поэтому framework, маршрутизация, state management, авторизация клиента, страницы, компоненты и механизм вызова backend документировать невозможно. Их не следует считать выбранными или реализованными.
